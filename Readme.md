# Shopping List Manager

## Features

### *Interactive Shopping List*

A simple and intuitive web application for managing your shopping list. The application allows you to:

* Add items to your shopping list with a clean input interface

* Manage item quantities with + and - buttons

* Remove individual items or reduce quantities

* Automatic quantity display (hidden when quantity is 1)

* Dynamic Item Management: You can add, modify quantities, and remove items seamlessly.

* Pure JavaScript: Built with vanilla JavaScript for optimal performance and no dependencies.

* Responsive Design: Clean and modern interface that works across different screen sizes.

* User-Friendly Interface: Intuitive controls with hover effects and smooth transitions.

## Technologies Used

This project is built using fundamental web technologies:

* HTML5: Semantic structure for the shopping list interface and form elements.

* CSS3 (with SCSS): Modern styling with CSS Grid/Flexbox, transitions, and responsive design patterns compiled from SASS.

* JavaScript (ES6+): Event handling, DOM manipulation, and interactive functionality using modern JavaScript features.

## How to Use

* Add Items: Type the item name in the input field and click "Ajouter" or press Enter to add it to your list.

* Manage Quantities: Use the + (`&#43;`) button to increase quantity or the - (`&#8722;`) button to decrease (items are removed when quantity reaches 0).

* Remove Items: Click the trash can icon (🗑️) to completely remove an item from your list.

* Visual Feedback: The application provides alerts for empty inputs and smooth hover effects for better user experience.
